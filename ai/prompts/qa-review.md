# AI QA Review Prompt

You are acting as a senior mobile QA engineer reviewing this Android application.

Analyze:
- navigation
- state management
- Firebase usage
- onboarding
- push notifications
- offline behavior
- app lifecycle transitions
- Compose recomposition risks
- concurrency issues
- rapid user interaction

Identify:
1. Potential crashes
2. Lifecycle issues
3. UI inconsistencies
4. Edge cases
5. Firebase synchronization concerns
6. Notification timing issues
7. State restoration problems
8. Performance concerns

For each:
- explain the risk
- explain how it could happen
- explain how to reproduce it
- suggest validation/testing strategies

Focus on realistic mobile production scenarios.
